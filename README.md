# AHRAM — Industrial Portfolio

بورتفوليو صناعي ثنائي اللغة مبني بـ **Next.js 16 + React 19 + TypeScript**، باستخدام أسماء وصور المنتجات الموجودة في موقع الأهرام الأصلي.

## التشغيل

يتطلب Node.js 20.9 أو أحدث.

```bash
npm install
npm run dev
```

افتح **http://127.0.0.1:3001**. تم اختيار منفذ 3001 لتجنب التعارض مع المشاريع الأخرى.

## بناء نسخة الإنتاج

```bash
npm run build
```

المشروع يستخدم `output: "export"`. نسخة النشر المستقلة موجودة داخل `out/`، وتعمل على أي استضافة تدعم الملفات الثابتة. لمعاينتها محليًا:

```bash
npx serve out -l 3001
```

`next start` لا يُستخدم مع الـ static export. للتحويل إلى خادم Next.js، احذف `output: "export"` من `next.config.ts` ثم أعد البناء وشغّل `npm start`.

## المحتوى والوظائف

- صفحة رئيسية تعرض هوية الشركة وخبرتها ونهجها الفني.
- كتالوج يضم 9 مجموعات منتجات، مع البحث بالعربية والإنجليزية والتصفية والترتيب.
- صفحة مستقلة لكل منتج مع منتجات ذات صلة ورابط المصدر.
- تبديل كامل بين العربية والإنجليزية مع RTL وحفظ اللغة محليًا.
- Skeleton للصفحات والصور، ودعم تقليل الحركة.
- نموذج استفسار يتحقق من المدخلات ويجهز مسودة `mailto:`. الإرسال يتم يدويًا من تطبيق البريد؛ لا توجد خدمة بريد أو قاعدة بيانات متصلة.
- قائمة متجاوبة، تنقل بلوحة المفاتيح، وعناوين وبيانات مشاركة لكل صفحة.
- الصور والخطوط مخزنة محليًا.

## تعديل المحتوى

| الملف | الوظيفة |
| --- | --- |
| `src/lib/products.ts` | بيانات المنتجات، الترجمات، الصور والمصادر |
| `src/lib/studio.ts` | بيانات مصباح، الشركة المطوّرة للموقع، وخدماتها ووسائل التواصل |
| `src/components/home.tsx` | محتوى الصفحة الرئيسية |
| `src/components/catalog.tsx` | البحث والفلاتر والترتيب |
| `src/components/site-provider.tsx` | اللغة ونموذج الاستفسار |
| `src/app/globals.css` | التنسيق وRTL والتجاوب |
| `public/images/` | الصور الأصلية |
| `src/components/skeleton.tsx` | مكونات Skeleton القابلة لإعادة الاستخدام |

هذا **تصور تصميمي مستقل** لبورتفوليو الشركة. أسماء المنتجات تشير إلى مجموعات وليست أصناف مخزون مؤكدة. لا يتضمن أسعارًا أو مواصفات فنية غير منشورة. تفاصيل المصادر في [CONTENT-SOURCES.md](./CONTENT-SOURCES.md).
